# Constitution

Written by hand. The Spec Kit CLI was not installed, so this is not a generated Spec Kit artifact and it is not a tool-reported CONVERGED state.

## Principles

1. GenLayer consensus classifies yield. Deterministic code decides capital eligibility.
2. Untrusted web text cannot change admin state, policy, or the verdict enum.
3. History is append-only.
4. The server never signs for a user.
5. Fixtures are labelled. Missing evidence is not invented.
6. A gate that was not executed is not marked passed.
