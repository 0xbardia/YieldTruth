# Roadmap

The same phases are on the `/roadmap` page. Planned items are not implemented.

## V1 — Semantic yield classification

In this build: evidence host registry, structured policies, `gl.vm.run_nondet` classification with code-level equivalence, deterministic decisions, reassessment, yield drift, a wallet write path, and a public explorer of labelled records.

The Studionet address is recorded in [deployment.md](deployment.md). Planned items below are not implemented.

## V1.1 — Monitoring

Scheduled re-evaluation, drift alerts, more protocol adapters, stricter per-source parsers.

## V1.2 — Integration layer

A consumer SDK for vaults and treasuries, policy templates, webhooks on finalized assessments.

## V2 — Capital routing

Policy-gated allocation hooks, wider protocol coverage, institutional controls. Not started. YieldTruth does not move capital.
